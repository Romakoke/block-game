# SchoolGuard — сайт для Vercel

Готовый статический сайт с прямыми ссылками на загрузку комплекта для Windows 10/11.

## Быстрая публикация (без GitHub)

1. Откройте https://vercel.com/drop .
2. Перетащите туда **внешний архив `SchoolGuard_Vercel_Site.zip`**, в котором лежат `index.html`, `assets/`, `downloads/` и `vercel.json`.
3. Назовите проект, нажмите **Deploy** и откройте выданную ссылку `.vercel.app`.
4. Проверьте скачивание архива и работу поиска по списку сайтов.

## Через GitHub

1. Создайте репозиторий в GitHub.
2. Распакуйте архив сайта и загрузите **содержимое** в корень репозитория.
3. В панели Vercel выберите **Add New → Project → Import Git Repository**.
4. Настройка Framework Preset: **Other**. Build Command не требуется. Output Directory по умолчанию.
5. Нажмите Deploy. Следующие обновления репозитория можно развёртывать автоматически.

## Структура

- `index.html` — страница
- `assets/styles.css` — оформление
- `assets/app.js` — поиск по адресам и меню
- `assets/favicon.svg` — иконка
- `downloads/school-filter-complete.zip` — архив блокировки
- `downloads/install-filter.bat` — установка
- `downloads/remove-filter.bat` — отмена изменений
- `downloads/blocked-sites.txt` — 78 игровых URL
- `downloads/instructions.txt` — инструкция
- `vercel.json` — заголовки скачивания и безопасность

## Важно

Это не полная блокировка всего интернета и не централизованный школьный фильтр.
Файл установки меняет системные политики Chrome, Яндекс Браузера и Edge, а также настройки DNS-over-HTTPS этих браузеров. Запускать только на компьютерах, которыми вы вправе администрировать. Ученические учётные записи должны быть без прав администратора.

В версиях Яндекс Браузера, не поддерживающих корпоративную категорийную фильтрацию, `games` и `porn` в настройках категорий могут не работать.
