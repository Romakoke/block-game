# ROLAB Download Center

Static multilingual download website prepared for Vercel.

## Included
- 3-language interface: Kazakh, Russian, English
- ROLAB-branded design aligned with the provided logo
- Download buttons for the blocking toolkit
- Footer with copyright text
- Instagram link

## Deploy to Vercel
1. Upload this folder or the ZIP archive to Vercel.
2. Set the project as a static site.
3. Deploy.
